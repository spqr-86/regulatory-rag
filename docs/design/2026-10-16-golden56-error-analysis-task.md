- Только чтение и анализ. **Платные прогоны (LLM, эмбеддинги, LangSmith-эксперименты) без «да» Петра не запускать.**
  Бесплатно: чтение файлов, офлайн-повтор сохранённых трейсов, `pytest`.
- Код проекта, `.env`, `chroma_db*` не менять. Писать только отчёт и временные скрипты вне репозитория
  (`/tmp/codex-golden56/`).
- Не отправлять данные во внешние сервисы, кроме чтения трейсов LangSmith проекта Петра.
- Каждое утверждение с числом — со ссылкой на источник (поле файла, run id, строка кода). Нет данных — писать «не проверено».

  затем приложение с таблицей 56×2. Русский язык, без воды.
- В конце отчёта — раздел «Что не удалось проверить и почему».

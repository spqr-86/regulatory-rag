Единый экран: объект или нормативная база

Regulatory RAG · UX/implementation spec · 21.09.2026

Решение: один главный экран и один расширенный выбор источника вместо двух переключателей. По умолчанию — «Закон + ЛНА для объекта». Generic-контур сохраняется, но отдельная пользовательская страница исчезает. Контракты и backend-пути не смешиваются.

Задача

Сейчас Department Q&A и Generic V7 выглядят как два приложения. Нужно оставить один понятный вход: пользователь либо проверяет применимость требований к выбранному объекту, либо ищет ответ только в нормативной базе. Во втором режиме интерфейс не должен показывать подразделение, профиль объекта и ЛНА.

Варианты

A. Один расширенный выбор источника

Плюсы: один продукт и один контрол; пользователь выбирает намерение через понятный источник.

Минусы: четыре варианта длиннее прежнего radio и требуют компактной раскладки.

B. Один вопрос, автоматический выбор

Система сама решает, нужен ли объект, и маршрутизирует запрос.

Плюсы: минимум контролов.

Минусы: скрытая магия, неоднозначный контракт, ошибки маршрутизации трудно объяснить.

C. Один смешанный ответ

Всегда искать нормы, ЛНА и объект, затем строить единый ответ.

Плюсы: единый backend-вызов.

Минусы: нормативный поиск загрязняется объектом, растут цена и задержка, теряется воспроизводимость Generic eval.

Принятый вариант A

  • Существующий radio «Корпус» переименован в «Где искать» и содержит четыре варианта.
  • Дефолт: «Закон + ЛНА для объекта».
  • Три объектных варианта сохраняют unit, профиль и текущий scoped Department service.
  • «Общая нормативная база» скрывает unit/profile; вопрос идёт в существующий Generic V7 runtime.
  • Результат нормативного режима показывает ответ, маршрут и источники; никаких выводов «применимо к объекту».
  • При смене режима результат и зависящее от формы session state сбрасываются.
  • pages/2_Общий_поиск.py удаляется из Streamlit-навигации; Generic backend, API и eval остаются.

Критерии приёмки

  • [ ] Главная страница открывается с «Закон + ЛНА для объекта» по умолчанию.
  • [ ] «Общая нормативная база» скрывает все объектные контролы.
  • [ ] Объектный запрос по-прежнему вызывает answer_scoped_question.
  • [ ] Нормативный запрос вызывает bound Generic V7 runtime, без Department service.
  • [ ] Смена режима не показывает ответ, полученный в другом режиме.

  • [ ] API, eval-раннеры и Generic unit-тесты не затронуты.

Выбран вариант A · 16.09.2026

Типизированный лист объекта

Разводим похожие величины до вызова модели: людей в зоне, на этаже, в здании и постоянные рабочие места. Поля показываются в prompt v4, а контракт ответа и decide() пока остаются прежними.

Почему меняем вход

В q1 модель второй раз сделала безусловный вывод о плане эвакуации, применив порог к другой величине. Prompt v3 уже содержал правило сверки порога, но ошибка повторилась дословно. Шаг 1 проверяет, достаточно ли явно разделить исходные факты.

Четыре архитектуры

A · выбрано

Поля → промпт

Строгие поля внутри листа, детерминированный парсер, отдельный блок в v4.

+ Изолирует качество входа

− Код ещё не проверяет вывод

B · при провале A

Поля как evidence

obj_f_* и структурная проверка порогов в decide().

+ Жёсткая гарантия

− Рано предполагает правильные ссылки модели

C · отклонено

Извлечение из текста

Regex или отдельный LLM превращает старые абзацы в поля.

+ Не надо менять листы

− Новый источник ошибок

D · отклонено

Ещё одно правило

Только усиливаем инструкцию модели без изменения данных.

+ Минимальная правка

− Этот путь уже провалился в v3

Поведение при ошибке

Все девять полей обязательны. Пропуск, дубль, лишнее имя, неверный раздел или значение останавливают загрузку с ObjectProfileError. Синонимы неизвестности не принимаются. Булево «нет» остаётся установленным фактом и не смешивается с «неизвестно».

Критерий q1 записан до прогона

Успех: только условный ответ или вопрос о численности в здании / постоянных рабочих местах на этаже.
Провал: любой безусловный вывод по нерелевантной величине. Тогда без ещё одной итерации промпта переходим к варианту B.

Приёмка

  • Четыре листа содержат все девять полей и проходят строгий парсер.
  • Prompt v1–v3 не изменены; режим v2 использует v4.
  • Поля показаны один раз и цитируются прежними obj_sN.
  • ModelAnswer, decide(), UI и retrieval не меняются.
  • Dry-run фиксирует v4 и новые sha до 9 платных вызовов.
  • Новый прогон помечен как новая база: изменились входные листы и expectations sha.

# Добавление вопросов в датасет

Датасет для оценки хранится в `tests/dataset.csv`. Это обычный UTF-8 CSV с двумя столбцами:

```
question,ground_truth
```

## Как добавлять вопросы

Открыть `tests/dataset.csv` в любом текстовом редакторе и дописать строки. Каждая строка требует:

- `question` — вопрос в том виде, как его введёт пользователь
- `ground_truth` — правильный ответ, конкретный и основанный на нормативных документах

**Хороший ground_truth:** содержит конкретные требования, сроки или ссылки.  
**Плохой ground_truth:** расплывчатый («зависит от ситуации») или слишком короткий («да, требуется»).

## Пример строки

```
Как часто проводится повторный инструктаж по охране труда?,Повторный инструктаж проводится не реже одного раза в 6 месяцев (п. 15 Приказа 2464).
```

## Категории вопросов

Стремиться к смеси из:
- Вопросов в области охвата (ответ есть в корпусе)
- Вопросов вне области охвата (система должна отказаться отвечать)
- Вопросов с ложной предпосылкой (система должна скорректировать предпосылку)

## После добавления вопросов

Запустить быстрый eval для проверки новых вопросов:

```bash
python eval/run_v7_eval.py --skip-judge --limit 10
```

Или протестировать один вопрос вручную:

```bash
python scripts/trace_v7.py "ваш вопрос здесь"
```

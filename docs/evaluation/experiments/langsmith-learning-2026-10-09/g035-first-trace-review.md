## Следствия для eval

Проверка OOS должна различать отсутствие генерации в графе и пользовательский текст отказа. По одному answer=null нельзя решить, что продукт показал пустой ответ. И одного route_decision=abstain недостаточно для покрытия этого раннего выхода: здесь решение определяется intent=noise.

scripts/trace_v7.py напечатал INFERRED PATH «intent_gate → router → rag_simple → [no retrieval]», но реальные узлы трейса показывают ранний выход. Это ошибка вспомогательной реконструкции пути, не исполнение router/rag_simple. Скрипт не менялся.

Ожидаемый отказ на уровне графа подтверждён. Отдельная end-to-end проверка текста UI остаётся невыполненной.

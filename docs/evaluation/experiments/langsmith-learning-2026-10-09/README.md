# Учебные прогоны LangSmith и калибровка citation judge

Материалы фактических прогонов 9 октября 2026 по LangChain Academy,
Reliable Agents. Это диагностика отдельных примеров, не оценка надёжности
системы или юридической актуальности документов. Отчёты — снимки на дату;
упоминания «следующего шага» в них не заменяют текущую задачу.
Текущий контракт и следующий шаг: [README оценщика](../../../../eval/judges/README.md).

## Реальный пример судьи — G019

Вопрос: как часто проводить тренировки по эвакуации при пожаре?
Ответ содержит документ и пункт 9, но пропускает раздел I,
который доступен во фрагменте 3. По согласованной рубрике ожидался `fail`.
GPT-4o и DeepSeek вернули `pass`: судьи приписали ответу реквизит из контекста.
Три искусственных контроля обе модели прошли, но этот реальный случай — нет.
Именно этот сбой мотивировал отдельные цитаты и вычисление статуса кодом.

Прогоны относятся к предыдущему промпту без `checks`, с указанным хэшем.
Это не результаты новой версии. Usage не сохранён, фактическая стоимость
не измерена. Один вызов на случай не устанавливает устойчивость.

## Слабые места RAG по ручному разбору трейсов

| Пример | Наблюдение | Установленное ограничение |
|---|---|---|
| [G006 — стажировка](g006-first-trace-review.md) | Верный минимум, нет пункта | Части п. 31 разнесены по контексту без явной связи |
| [G019 — эвакуация](g019-first-trace-review.md) | Верная периодичность, отсутствуют раздел и числовое определение условия | Данные были во входе; генерация их опустила |
| [G043 — ложная посылка](g043-first-trace-review.md) | Ложная посылка исправлена, но перечень оборван и нет пункта | Части п. 72 есть во входе, связь не сохранена явно |
| [G035 — вне предмета](g035-first-trace-review.md) | Граф остановился до retrieval/generation | Отказ в UI не проверен; inferred path скрипта не соответствует фактическому трейсу |
| [G001 — программа А](g001-program-a-trace-review.md) | Потеря категорий, области применения и искажённые номера | Нужные чанки найдены, но исключены при merge/выборе кандидата |
| [G020 — медосмотр водителей](g020-drivers-medical-trace-review.md) | Табличная строка найдена, но генератор её не получил | Merge потерял чанк; кандидат с ним отвергнут по refs_resolved, выбран старый fallback |

Для G001 установлен механизм: при merge приоритет vector_score над
rerank_score, затем закрепление старых фрагментов и обрезка кандидата.
Для G020 строка #319 присутствует в last_attempt, но не в выбранном
fallback. Генератор корректно сообщает нехватку конкретной опоры и
приводит общую норму. Технический success не означает качественный ответ.

Эти проблемы не исправлялись в рамках упражнения. G001/G020 не имеют
верифицированного эталона и не включаются в verified-метрики.
Новые платные сравнения, изменения графа и переиндексация требуют
отдельного решения; чтение сохранённых доказательств нового API-вызова не требует.

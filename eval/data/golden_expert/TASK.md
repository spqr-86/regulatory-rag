# Задача: golden-кейсы из реальных вопросов с ответами экспертов

Цель — кандидаты в golden-датасет regulatory-rag: реальный вопрос человека + опубликованный
ответ эксперта со ссылкой на норму. Ответ эксперта — черновик эталона; проверку по тексту нормы
делает человек позже. Поэтому главное — подлинность и прослеживаемость, а не количество.

## Партия

Партия задаётся при запуске: тема и файл вывода. Размер партии — 50 кейсов, из них 5 с ложной
предпосылкой (автор вопроса исходит из неверного, эксперт это поправил).

## Источники, по приоритету

1. Официальные ответы ведомств: Роструд («онлайнинспекция.рф», раздел вопросов), Минтруд, МЧС,
   ФНС, Минфин и т.д.
2. Рубрики «вопрос-ответ» правовых систем и профильных изданий, где отвечает эксперт.
3. Ответы юристов/специалистов на открытых площадках (форумы, pravoved.ru и аналоги) — только со
   ссылкой на конкретную норму.

## Жёсткие правила

- Каждый кейс — со страницы, которую ты открыл веб-поиском. Не по сниппету, не по памяти.
- Вопрос — дословно, как задал человек (орфографию не править). Ответ эксперта — дословная
  ключевая часть, до 3 предложений.
- Ничего не выдумывать и не перефразировать. Не нашёл — меньше кейсов, это нормально.
- Ответ без ссылки на конкретную норму (акт + статья/пункт) — кейс не брать.
- Ответ держится на судебной практике, а не на тексте нормы — не брать.
- Попытайся опровергнуть каждый ответ эксперта: более поздняя редакция нормы, противоречащее
  разъяснение другого ведомства. Нашёл — запиши в `risk`, кейс не выбрасывай молча.
- Один акт — не больше 20 % кейсов партии. Дубли по смыслу не брать.
- Распределение типов примерно: fact 25 %, list 15 %, number 10 %, condition 15 %,
  multi_act 15 %, liability 10 %, false_premise 10 %.
- Никакого обзора методологии, только сбор.
- Уроки партии 1: квоты типов не выполнены (list 0, condition 42 %). Целенаправленно ищи вопросы
  «кто/что входит», «какие документы», «сколько/какой срок», вопросы на стыке двух актов.
  `answer_date` — дата ответа со страницы (у Роструда она есть рядом с ответом); пусто только
  если её действительно нет. Если тема позволяет, бери не только уровень 1.

## Вывод

CSV, разделитель `;`, UTF-8, кавычки по RFC 4180, заголовок:

```
id;question;expert_answer;answered_by;source_level;url;answer_date;norm_ref;norm_changed;type;risk
```

- `id` — префикс партии + номер (`OT-001`)
- `source_level` — 1/2/3
- `answer_date` — ГГГГ-ММ-ДД, если на странице нет — пусто
- `norm_ref` — акт, статья/пункт/подпункт (`ПП РФ № 2464, п. 53`)
- `norm_changed` — `да: <что и с какой даты>` / `нет` / `не установлено`
- `type` — fact | list | number | condition | multi_act | liability | false_premise
- `risk` — пусто или: `расходятся` / `устарел` / `<короткая заметка>`

Рядом — `<файл>.summary.md`: акт → число кейсов; чего не удалось набрать и почему; какие
источники пробовал и где не было доступа.

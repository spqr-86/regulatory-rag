# MISC — жилищное и семейное право, КоАП, персональные данные

Дата сбора: 18.10.2026. Сохранены **10 кандидатов MISC-001–MISC-010 из запланированных 50**. Пять случаев с ложной предпосылкой не набраны: в отобранных вопросах нет достаточно явно выраженного ошибочного утверждения автора. Полная партия по числу и квотам не выполнена.

Все десять страниц с вопросами и ответами открыты веб-инструментом. Вопросы сохранены целиком в опубликованной формулировке; ответы — короткие дословные выдержки. Несколько выдержек являются частью предложения: опущенные условия и контекст указаны в `risk`. Публикации ведомств не позволяют удостоверить, насколько редакция изменила первоначальное обращение гражданина; сохранен именно опубликованный текст.

## Типы и недобор

| Тип | Кейсов |
| --- | ---: |
| fact | 2 |
| list | 0 |
| number | 4 |
| condition | 3 |
| multi_act | 0 |
| liability | 1 |
| false_premise | 0 |

Не набраны 40 строк, пять ложных предпосылок, списки и вопросы, требующие совместного применения нескольких актов. Наличие двух статей одного кодекса не считалось `multi_act`. Вопрос о допустимости действия сам по себе не считался ложной предпосылкой.

Основные причины недобора: закрытые ответы; отсутствие конкретной статьи или пункта в ответе; опора на судебную практику; отсутствие подтверждения, что перед нами вопрос гражданина, а не редакционный FAQ. Дополнительное ограничение сбора — не более 25 дословно воспроизводимых слов с одной страницы: длинные обращения не сокращались и не заменялись заголовком, если в тексте был более полный вопрос. Это исключило, в частности, вопросы о неустойке по алиментам, разводе с осуждённым супругом, перерасчёте коммунальных услуг при вахтовой работе и обработке данных пациентов. Короткие ответы местами требуют контекста из `risk`; они остаются кандидатами для ручной проверки, а не готовыми эталонами.
